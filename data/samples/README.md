# Sample-frame policy

`index_100_frames.csv` contains the source IDs, frame indices, class IDs, dimensions, bounding boxes, label-file paths, and official source URL for 100 validated samples.

The JPEGs under `frames/` are intentionally excluded from this handoff repository to avoid distributing dataset-derived media. Recreate them from the official Svanstrom source using `scripts/dataset/extract_samples.py` and seed `20261003`.
